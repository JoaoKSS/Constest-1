## 🚀 Como clonar e compilar

1. 📋 Clone o repositório:
   ```bash
   git clone https://github.com/JoaoKSS/Constest-1.git
   cd Constest-1
   ```

2. ⚙️ Compile e execute:
   ```bash
   git checkout ContestA
   g++ -std=c++17 contest-1-A-joao-kennedy-souza-soares.cpp -o contestA
   ./contestA < input.txt
   ```
